# Playwright Notes

이 폴더는 "자동화 코드 자체"보다 "어떤 시나리오를 자동화 대상으로 선택했는가"를 보조적으로 보여주기 위한 용도다.

## 자동화 원칙

- 전환에 직접 영향을 주는 흐름부터 자동화
- 공개 페이지에서 안정적으로 재현 가능한 시나리오 우선
- 과도한 구현보다 읽기 쉬운 테스트 유지

## 현재 포함 시나리오

- 랜딩 핵심 카피 및 다운로드 CTA 노출
- 다운로드 모달 오픈
- 언어 전환 후 영어 페이지 기본 렌더링
- 지역 검색 입력 및 결과 섹션 반응 확인

## 실행 예시

실제 실행용 설정 파일은 아직 넣지 않았고, 포트폴리오 골격만 먼저 구성했다.
원하면 다음 단계에서 `package.json`, `playwright.config.ts`, 브라우저 실행 스크립트까지 바로 이어서 붙일 수 있다.
